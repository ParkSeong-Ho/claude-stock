# 04. 구조 — 중급 (정식 용어와 계산식)

> 목차는 [03 초급](03-구조-초급.md)·[05 고급](05-구조-고급.md)과 같다. **굵은 글씨**는 처음 나오는 용어이고, 바로 뒤 괄호에 뜻을 적었다.

---

## 1. 한 줄 요약
세 트레이너 전략의 **유휴 현금**(주식에 안 쓴 돈)을 지수 ETF/지수에 넣는 규칙(A1)과 현금으로 두는 규칙(A0)을, 같은 신호·같은 팀장 판정으로 **포워드 모의매매**(앞으로 오는 실제 시세로 하는 가짜 매매)해 63거래일 동안 **운영 기준**을 확인한다.

## 2. 왜 만들었나
- R2 **백테스트**(과거 시세로 규칙을 돌려 본 것)에서 A1 이 A0 를 크게 이겼다. 하지만 백테스트는 미래 정보가 섞이거나(미리보기), 실제 운영의 자료 지연·장애를 겪지 않는다.
- 그래서 **사전 등록**(판정 기준을 결과 보기 전에 커밋)을 하고, 포워드로 "장부가 틀리지 않고 매일 도는가"를 본다. 수익률은 표본이 짧아 판정에서 뺀다.

## 3. 등장인물
| 용어 | 뜻 |
|---|---|
| **트레이너** | 규칙 기반 전략. 마라토너(장기 추세: 20일선>60일선 + RSI 40~50 눌림 매수, 손절 −15%)·스프린터(단기: 5/20일선 골든크로스, 익절 +3%·손절 −2%·3일 시간 제한)·파이오니어(공격형: 골든크로스+거래량 급증 또는 RSI 35 이하 반등, 익절 +10%·손절 −5%). 예산 60/30/10%, **종목 상한** 30/20/15%(시작 예산 기준) |
| **장부(ledger)** | 지갑(현금·보유) + 보유 포지션 + **대기 주문**(내일 시가에 체결할 주문) + 기록. 시장마다 A0·A1 × 3 = 6개 |
| **대기 자산(idle asset)** | A1 의 쉬는 돈이 들어가는 곳. 미국 SPY, 국내 KS200(KOSPI 200 가격지수). **소수 단위**로 보유 |
| **팀장(analyst)** | `claude -p` 로 후보마다 buy/hold/veto 와 **확신도**(0~1)를 받음. 없으면 규칙 그대로(**폴백**) |
| **스크리너** | 종목군에서 매수 신호를 낸 후보를 고름 |

## 4. 하루가 흘러가는 순서
- **확정 봉**(장이 끝나 값이 확정된 하루치 시세)만 쓴다. 미국 16:15 ET, 국내 종목 16:00 KST, KS200 은 22:30 KST 뒤에야 오늘 봉을 인정.
- **신호는 봉 t 종가, 체결은 봉 t+1 시가**(미리보기 방지).
- 한 봉 안 순서
  1. 시가: (S+1 이면 A1 전부 지수) → 상장폐지 정리 → **매도** → **매수**(A1 은 부족분만 지수 매도) → A1 **쓸어 담기**
  2. 종가: 보유 평가(정지 종목은 마지막 거래 종가) → 매도 판단 → 신규 후보 → 팀장 → 다음 시가 주문
  3. 점검 → 저장
- 맥이 꺼져 있었으면 밀린 봉을 오래된 것부터 하나씩 처리(**따라잡기**). 다음 장 시작 뒤 처리한 봉은 **늦은 봉**(팀장 대신 폴백).

## 5. 돈 계산 규칙
- 비용: 체결가 E = P·(1+**슬리피지**)(매수) / P·(1−슬리피지)(매도). 수수료 = 금액 × 수수료율. 국내 주식 매도는 **거래세**(체결일 기준 날짜별 표, 2026년 0.20%). 지수 다리는 매도세 0.
- 매수 필요 금액 `need = E·n + E·n·fee` (n = 상한 안에서 살 수 있는 정수 주).
- A1 매수 가능: `need ≤ (현금 + 지수단위·u_net)·(1−1e-9)`. u_net = 지수 1단위를 팔면 받는 돈. 모자라면 `(need−현금)/u_net·(1+1e-9)` 만큼만 지수 매도. 1e-9 는 경계에서 "지수만 팔고 매수 실패"를 막는 **여유값**.
- A1 쓸어 담기: 현금 ≥ 1 이면 `현금 ÷ (Q·(1+slip)·(1+fee))` 단위를 산다(조금 줄여 가며 성공할 때까지).
- A0 는 현금 부족이면 그냥 **보류**(skip, 이유를 기록).

## 6. 기록과 저장
- **판정 기록**(`analyst_cache.jsonl`): 팀장 판정을 (시장|날짜|트레이너|종목) 열쇠로 **추가만** 하는 파일. 장부보다 먼저 디스크에 씀(fsync). 두 장부는 같은 열쇠를 재사용 → 같은 판정.
- 장부 칸: `orders`(주문 생애), `fills`(체결), `skips`(보류), `days`(하루 기록: 평가액·종가·사건), `corp_actions`(분할·상장폐지·정정).
- **커밋 지점(HEAD)**: 백업 → 장부 6개(.tmp → 교체) → `HEAD.json` 교체. HEAD 가 가리키는 상태만 "저장됨". 읽을 때 지문이 다르면 백업으로 되살림.
- **잠금**: 모든 명령이 같은 잠금 파일을 잡는다(동시 실행 방지).
- **멱등**: 같은 봉으로 다시 돌려도 장부·판정 기록이 바뀌지 않음.

## 7. 잘못을 찾는 장치
| 등급 | 예 | 처리 |
|---|---|---|
| **L 장부 논리 오류** (L1~L24) | 현금 음수, 체결가 ≠ 그날 시가, 중복 주문, 정지일 체결, 평가액 불일치, 파일 손상 | 종료 코드 2, 그 봉 저장 안 함 → 재시작 대상 |
| **D 자료 문제** (D1~D7) | 시세 못 받음, 늦은 행, 달력 줄어듦·구멍, **소급 수정**(지난 값이 바뀜 — 분할 등), 기준 지수 늦음 | 종료 코드 4/7, 그날만 멈춤 |
| **W 경고** | 늦은 봉, 정지, 팀장 폴백 | 기록만 |
- **그림자 서킷**: 서킷 브레이커(누적 −10% 또는 하루 −7%면 정지)를 장부에는 끄고, "켜졌다면"을 매일 계산해 기록만.
- **관문(gate)**: 코드 지문 + 라이브러리 버전 조합이 "재현 통과 기록"에 없으면 실행 거절(종료 코드 3).

## 8. 판정
- **판정 창** = S ~ S+62(63봉), 시장별, S+62 처리 직후 한 번.
- 운영 기준: L 0건 / 빠진 날 0·늦은 봉 ≤ 10·한 번에 ≤ 5 / 재현 통과 코드만.
- 재시작: 정해진 이유(L 오류, 늦은 봉 초과, 허용 안 된 코드 변경)만, 최대 2번, 마감 2027-06-30.
- **거짓 양성 예외(사전 등록 ④)**: L 이 점검 함수의 잘못이면, 고친 코드로 다시 처리한 장부 내용 지문이 그때 저장하려던 지문과 같고 재현 지문도 같을 때만 재시작 없이 이어 감(프로그램이 자동 기록).
- **코드 동결**: 판정 창 중 코드·라이브러리 변경 금지(자료 받기 고침·세율 줄 추가만 조건부 허용).

## 10. 믿을 수 있는 근거
- **골든 테스트**: 변경 전 코드(847ad13)의 운영 루프 출력·상태 파일을 저장해 두고 바이트 비교.
- **차등 재현**(differential): 같은 입력을 R2 시뮬레이터와 새 엔진에 넣어 체결·평가액을 비교 → W1(2026-06~11 미·국)·W2(2018 국내) 6조합 완전 일치.
- **음성 대조**: L·D 코드마다 일부러 틀린 장부·자료를 넣어 그 코드가 나는지 시험.
- **돌연변이 시험**: 코드를 일부러 틀리게 바꿔 시험이 실패하는지(시험이 진짜로 지키는지) 확인.
- **독립 검토**: 단계마다 작성자 설명 없이 코드만 보는 검토 → 수정 → 재실행.
