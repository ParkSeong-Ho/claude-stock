## 읽는 법 (권장)

1. **01 → 02** 를 먼저 읽는다. 무엇을 왜 만들었는지 알아야 구조가 보인다.
2. **03·04·05 는 목차가 같다**(1절 한 줄 요약 … 10절 믿을 근거). 한 버전을 다 읽고 다음으로 가기보다, **같은 절을 초급 → 중급 → 고급 순서로 이어 읽는 것**을 권한다. 같은 내용이 어떤 단어로 압축되는지가 보인다.
3. 모르는 단어가 나오면 **06 용어 사다리**에서 그 단어 줄을 찾는다. 왼쪽으로 갈수록 쉬운 말이다.
4. 복습할 때는 **07 오류노트**의 점검 질문에 먼저 답해 보고 답을 연다. 같은 종류의 실수(거짓 양성·거짓 통과·잘못 분류)가 어떻게 반복되는지 보인다.

## 이 묶음을 이렇게 만든 이유 (사용자 제안에 대한 의견)

- 사용자 제안: "초급·중급·고급으로 나누고, 고급으로 갈수록 금융·프로그램 단어로 압축해 맥락을 이해하게".
- 의견: **방향은 맞다.** 같은 내용을 세 번, 점점 압축해서 보면 단어와 흐름이 같이 익는다.
- 보완한 것 두 가지
  - 압축된 용어는 **한 번 풀어 본 뒤에야** 압축으로 읽힌다. 용어만 빽빽하면 오히려 흐름이 안 보인다. 그래서 세 버전의 **목차를 똑같이** 맞추고, 단어를 이어 주는 **06 용어 사다리**를 더했다.
  - "생각의 구조"는 머릿속을 그대로 옮긴 기록이 아니다. 실제로 쓴 **판단 원칙과 결정 기록**(설계 §10, 검토 문서)을 정리한 것이다(02).
