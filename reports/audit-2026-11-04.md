## 0. 요약 — 먼저 알아야 할 8가지

1. **문서는 옛 숫자, 코드·프롬프트는 새 숫자.** 스프린터 익절/손절은 기획서 +3%/-2%, 코드·프롬프트 +5%/-1.5%. 실행되는 건 코드다. 근거(튜닝 결과)는 v1 이전 조건(같은 종가 체결, `max(1,…)`, 원·달러 합산, 옛 비용)에서 나온 것이라 **v1 실측에서 다시 확인해야 한다**.
2. **파이오니어 RSI 기준이 세 군데에서 세 값.** 기획서 30, 코드 35, 프롬프트 본문 40(같은 파일 코칭 로그는 35). 실행값은 35.
3. **비용이 실행 경로마다 다르다.** `main/tune/validate/universe_check`는 D8(수수료 0.1%·매도세 0·슬리피지 0.05%)을 쓴다. 그런데 `team.py`는 v1 이전 상태 파일을 그대로 읽으면 옛 비용(수수료 0.015%·매도세 0.18%)을 계속 쓰고, `live.py`는 수수료만 상태에서 읽어서 왕복 비용이 **0.13%**로 줄어든다. 문서 쪽(공유사항:17)은 아직 "0.18% 유지"라는 옛 결정이 최신이다.
4. **총 가상자금 1,000,000(코드, 주석 "100만원") vs $10,000(설계).** $10,000에 D5(1주도 못 사면 보류)를 같이 적용하면 파이오니어 종목당 한도가 **$150**이 된다. v1 종목(AAPL·MSFT·NVDA·GOOGL·AMZN) 대부분이 1주에 $150를 넘어서 파이오니어가 거의 매매하지 못한다(추정). → **$100,000을 권한다**(§2 C7).
5. **서킷 브레이커 값(-10%/-7%)은 모든 문서·코드가 같다.** 다만 `main.py`처럼 한 종목만 매매할 때는 하루 -7%가 사실상 발동하지 않는다(종목이 하루에 23~47% 빠져야 함). 기획서의 "N일 연속 손실"과 "재개 대기"는 구현되지 않았다(D6 범위).
6. **문서에 없는 숫자가 성적을 좌우한다.** `MAX_POSITIONS=5`(team.py:31)와 종목상한이 겹치면서 마라토너는 실제로 **3종목까지만** 살 수 있다. 4번째 매수는 현금이 모자라 조용히 실패한다.
7. **팀장 페르소나는 "확신 없으면 hold"라고 하는데 코드는 hold를 거르지 않는다.** 걸리는 건 `veto`와 `conviction < 0.5`뿐이다. hold에 conviction 0.6을 주면 그대로 매수된다.
8. **D4(미국 전용·달러)와 충돌하는 문장이 문서와 코드 곳곳에 남아 있다.** README 종목 예시(삼성전자), `main.py`·`validate.py` 종목 목록의 국내 종목, 출력의 "원", 기획서 §3.1 예시 금액(10만/20만/5만)이 그렇다.

## 2. 값이 다른 곳마다: 실행값 / 영향 / 권장

이 문서가 권하는 기본 원칙은 이렇다. **문서는 지금 실행되는 코드 값으로 맞추고, "잠정·v1 실측에서 재확인"이라고 적는다.** 이유는 세 가지다. (1) 포워드 데이터가 2026-09-17부터 이 값으로 쌓이고 있다. (2) 설계 §1이 전략 숫자 튜닝을 v1 비목표로 정했다. (3) 문서를 옛 값으로 되돌리면 그 값에는 v1 조건으로 측정한 근거도 없다. 값을 실제로 바꾸는 일은 `run/v1-measure` 결과를 본 다음에 한다.

### C1. 스프린터 익절·손절: +3%/-2% (기획서) vs +5%/-1.5% (코드·프롬프트)

- **실행값:** +5% / -1.5% (sprinter_brain.py:25). `main`·`live`·`team`·`validate` 모두 이 기본값을 쓴다. `tune.py`만 두 값을 다 돌린다.
- **영향 추정:** 왕복 비용 c = 0.30%(D8)로 놓고, 시간제한 청산을 빼고 계산한 손익분기 승률 = (손절폭 + c) / (익절폭 + 손절폭).
  - +3%/-2%: 2.3 / 5.0 = **46%**
  - +5%/-1.5%: 1.8 / 6.5 = **28%**
  - 즉 지금 값은 "가끔 크게 이기고 자주 조금 지는" 구조다. 다만 손절 판정은 **일봉 종가**로 하고(sprinter_brain.py:65), D3 이후에는 체결이 **다음 날 시가**로 바뀐다. 대형주의 하루 변동이 1.5~2% 수준이라 실제 손절 손실은 -1.5%보다 커질 가능성이 높다(추정, 예를 들어 -2.5%). 그러면 손익분기 승률은 (2.5+0.3)/(5+2.5) ≈ 37%로 올라간다. **손절폭이 좁을수록 D3의 타격이 크다.**
  - 코드 주석(sprinter_brain.py:29-30)은 옛 기본값의 검증 손익 -22,685를 +11,560으로 바꿨다고 적는다. 이 숫자는 같은 종가 체결, `max(1,…)`, 원·달러 합산, 옛 비용 조건에서 나왔고, RSI 문턱(C2) 변경 효과도 섞여 있다. v1에서 이 차이가 그대로 남는다고 보장할 수 없다.
- **권장:** 문서를 **+5% / -1.5% (잠정)**으로 맞춘다. 기획서:49, 102, 298과 sprinter_brain.py:9-10 docstring이 대상이다. v1 실측에서 `tune.py`를 D3 조건으로 다시 돌려 -1.5%와 -2%를 비교한다. 체결 지연 때문에 -1.5%가 무너질 가능성이 가장 큰 숫자라서 실측 보고서의 첫 확인 항목으로 둔다.
