# AI 트레이너 가상매매 — 사용 안내서 (초보자용)

> 🟢 **이건 "가짜 지갑" 학습 모드예요. 진짜 돈은 한 푼도 안 들어갑니다.**
> 실제 주가만 가져와서, 세 트레이너가 규칙대로 매매하는 걸 "연습"으로 돌려봅니다.
> v1은 **미국 종목 전용, 가짜 지갑은 달러($10,000)** 입니다. (설계: `docs/v1-design.md`)

---

## 이 폴더에 뭐가 들었나

| 파일 | 역할 (쉽게) |
|---|---|
| `main.py` | **과거 전체로 한 번에 연습.** 실제 주가를 가져와 세 트레이너를 가상매매 시킴 |
| `live.py` | **매일 한 번 실행.** '오늘 하루'만 판단하고 저장해 내일 이어서 (포워드 검증) |
| `tune.py` | 익손절·조건 값을 여러 조합으로 쓸어보고 성적을 CSV로 기록 (조건 손볼 근거 만들기) |
| `validate.py` | 과최적화 점검: 지금 값이 여러 국면·여러 시대에서 버티는지 검사 (규칙 바꿀 때마다) |
| `screener.py` | 부하(트레이너)가 넓은 종목군에서 자기 스타일 '매수' 후보를 스스로 찾음 |
| `analyst.py` | 팀장(Claude)에게 `claude -p`로 연락해 후보 분석·veto 받는 다리 (구독, 없으면 규칙 폴백) |
| `team.py` | **팀장 일일 루프**: 스크리너→팀장 분석→규칙 판단→가상 체결을 한 번에 (진짜 돈 0원) |
| `prompts/` | 트레이너별 페르소나 + 코칭 로그(성장 기록) |
| `paper_wallet.py` | 가짜 지갑 (사고팔고 손익계산) |
| `risk_guard.py` | 서킷 브레이커 (손실이 한도 넘으면 자동 전량정리+정지) |
| `sprinter_brain.py` | 스프린터(단타) 두뇌 |
| `marathoner_brain.py` | 마라토너(롱런) 두뇌 |
| `pioneer_brain.py` | 파이오니어(리스크) 두뇌 |
| `results/` | `main.py` 결과: 거래내역·일별 평가금액 CSV (자동 생성) |
| `state/` | `live.py`·`team.py`가 다음 봉에서 이어가려고 저장하는 상태·대기 주문 (자동 생성) |
| `error_log.txt` | 오류가 나면 여기에 자동으로 기록됨 (처음엔 없음) |

## 처음 한 번만: 준비하기

1. **파이썬 설치** (이미 있으면 건너뛰기)
   - https://www.python.org 에서 최신 버전 설치. 설치 중 "Add Python to PATH" 체크.
2. **필요한 라이브러리 설치** — 터미널(명령 프롬프트)에서 딱 한 줄:
   ```
   pip install finance-datareader ta backtesting
   ```

> 터미널 여는 법: 윈도우는 시작 메뉴에 `cmd`, 맥은 `터미널` 검색.

## 실행하기

터미널에서 이 폴더로 이동한 뒤:
```
python main.py
```
- 잠시 뒤 종목별로 세 트레이너의 가상매매 성적표(순손익·승률·**MDD**·마지막 판단 이유)가 나옵니다.
- 트레이너마다 **비교 한 줄**이 붙어요: 같은 돈으로 첫날 사서 그냥 들고 있었으면(buy&hold) 얼마였는지,
  같은 기간 **SPY(미국 시장 전체)** 는 몇 % 올랐는지. "이겼다"는 이 비교로만 말합니다.

#### v1에서 바뀐 매매 규칙 (현실에 맞춤)
- **확정 봉만 씀:** 종가가 빈 봉, 아직 장이 안 끝난 오늘 봉(뉴욕 16:15 전)은 버려요.
- **체결은 다음 거래일 시가:** 오늘 종가를 보고 "사자/팔자"를 정하면, 실제 체결은 **다음 날 시가**예요.
  그래서 백테스트 마지막 날의 신호는 "미체결 주문"으로 표시돼요.
- **상한을 넘겨 1주 사지 않음:** 종목상한(예산×비율) 안에서 수수료·슬리피지까지 내고 1주도 못 사면
  **매수 보류**하고 사유를 거래내역에 남겨요(종류 = 보류).
- 비용: 수수료 0.1%(살 때·팔 때), 슬리피지 0.05%, 매도세 0.
- 거래내역과 일별 평가금액은 `results/` 폴더에 CSV로 저장됩니다.
- **진짜 돈은 안 들어갑니다.** 그냥 "이 규칙이면 이렇게 됐겠다"를 보여줄 뿐이에요.

### 매일 이어서 연습하기 (라이브 가상매매)
```
python live.py
```
- 하루 한 번 실행 → **새로 확정된 봉**만 판단하고 `state/` 폴더에 저장 → 다음 봉에서 이어서 진행.
  미국 장 마감 뒤(뉴욕 16:15 이후 = 한국 다음날 아침 6~7시쯤) 돌리는 걸 추천해요.
- 오늘 신호는 `state/`에 **대기 주문(pending)** 으로 저장되고, 다음 실행 때 새 봉의 **시가**로 체결돼요.
- 과거에 끼워맞추지 않은 **미래(포워드) 검증**입니다. 최소 1~3개월 돌려 "안 잃는지" 확인하세요.
- 몇 번을 돌려도 같은 봉이 두 번 반영되지 않아요. 새 확정 봉이 없으면(주말·휴장·장중) 아무것도 안 바꿔요.
- 예전(원화) 상태 파일이 있으면 이어 쓰지 않고 `*.old-날짜.json`으로 보관한 뒤 새로 시작해요.
- 끝에 트레이너별로 시작일부터의 손익을 buy&hold·SPY와 비교한 줄이 나와요.

### 팀장 일일 루프
```
python team.py 40
```
- 스크리너(S&P500 40종목) → 팀장(Claude) 분석 → 규칙 판단 → **다음 시가 주문**을 한 번에.
- 팀장이 `hold` 라고 하거나 확신도가 0.5 미만이면 매수 보류(사유가 거래내역에 남음).
- 세 트레이너가 이미 마지막 확정 봉까지 처리했으면 스캔도 안 하고 바로 끝나요.
- 손실이 커지면(누적 -10% 또는 하루 -7%) **서킷 브레이커**가 자동으로 전부 팔고 그 트레이너를 멈춥니다.

### 규칙 값 튜닝하기 (조건 손보기 전에)
```
python tune.py
```
- 스프린터 익손절·진입문턱, 파이오니어 매수조건을 **여러 값으로 쓸어보고** 성적을 `results/tune_*.csv`에 전부 기록.
- 기간을 **훈련(앞 60%)/검증(뒤 40%)**으로 나눠 봅니다: 훈련만 좋고 검증이 나쁘면 과최적화 → 버림. 검증까지 좋은 값만 채택.
- ⚠️ 검증까지 좋아도 미래 보장은 아니에요. 고른 값은 `live.py`로 포워드 검증하세요.

### 과최적화 점검 (규칙 바꿀 때마다 — 중요)
```
python validate.py
```
- 지금 값이 **여러 시장 국면**(2018 조정·2020 폭락·2022 약세장·2023~ 상승)과 **서로 다른 시대**에서
  모두 버티는지 검사합니다.
- 한 시대만 좋고 다른 시대에서 손실/하위권이면 **"그 시대에 끼워맞춘(과최적화)"** 신호 → ⚠️ 경고를 띄웁니다.
- 규칙·숫자를 바꿀 때마다 이걸 돌려서, 과거에 끼워맞춘 건 아닌지 늘 의심하고 점검하세요.

## 종목이나 기간 바꾸기

`main.py` 위쪽 `CONFIG` 부분의 숫자만 바꾸면 됩니다. (코드 몰라도 됨)
```python
"종목목록": {
    "애플": "AAPL",         # 미국 티커
    "엔비디아": "NVDA",
},
"시작일": "2023-01-01",
"총_가상자금": 10_000,      # 달러
```
- 티커는 야후 파이낸스 등에서 검색하면 나옵니다.
- 다른 종목을 넣고 싶으면 이 목록에 한 줄 추가하면 돼요.
- ⚠️ v1은 **미국 종목만** 넣으세요. 한국 종목(6자리 코드)은 지갑이 달러라 금액이 섞여요.

## 오류가 나면? (당황 금지)

1. 프로그램이 **안전하게 멈춥니다.** (돈은 절대 안 나갑니다 — 애초에 가짜 지갑이라)
2. `error_log.txt` 파일에 무슨 오류인지 **자동으로 기록**됩니다.
3. 그 파일을 **Claude Code로 열어서 "이 오류 고쳐줘"** 라고 하면 됩니다.
   - Claude Code가 이 폴더의 파일을 직접 읽고 고쳐줍니다.
