만든 명령 (저장소 루트에서):
```bash
S=<scratch 폴더>
git worktree add $S/wt847 847ad13
cp tests/golden_scenarios.py $S/wt847/tests/golden_scenarios.py
(cd $S/wt847 && ~/.venv-cs/bin/python tests/golden_scenarios.py --write $S/golden-847)   # "가지 확인 통과" 가 찍혀야 함
rm -rf tests/golden/us tests/golden/kr && cp -r $S/golden-847/us $S/golden-847/kr tests/golden/
git worktree remove --force $S/wt847      # 복사해 넣은 장면 파일·__pycache__ 때문에 --force
```
`golden_scenarios.py` 는 자기 위 폴더의 저장소 모듈(`team`·`main`·`screener`·`analyst`·`paper_wallet`·`markets`·`metrics`·`risk_guard`·브레인 3개)을 읽고, 하나라도 다른 폴더 것을 읽으면 바로 멈춘다.

## 무엇이 들어 있나

`<시장>/<장면>/` 마다
- `stdout.txt` — `team.run(N, market)` 의 화면 출력 그대로
- `step.json` — 장면 설정(실행 시각·시세 끝 날짜·팀장 모드·그 장면에서만 받기 실패하는 코드·상태 손질), 그 실행에서 가짜 claude 가 받은 호출(프롬프트 전체·인자·환경에 API 키가 빠졌는지·가짜 답), 같은 시각 `screener.scan(N, market)` 결과(`used`·`found`)
- `state/…` — 실행 뒤 상태 폴더의 파일 전부(`team._save` 가 쓴 바이트 그대로). 저장 안 한 날은 앞 장면과 같다

## 바꿔 끼운 곳 (입출력 경계만)

- `FinanceDataReader`(`DataReader`·`StockListing`) → 합성 시세. 정수 난수 + 곱셈 + 반올림만 써서 어느 컴퓨터에서나 같은 값
  - 미국 목록 16칸: 정상 12, 빈칸(NaN) 1, `FAIL`(늘 받기 실패), `NEWB`(2026-06-22 상장 → 09-25 에 70봉), `STAL`(09-08 에 자료 끝, 그 봉에 매수 신호). `LIMA` 10-01 은 시가 NaN(거래량 있음)
  - 국내 `KR_UNIVERSE` 앞 10개: `373220` 늘 받기 실패, `329180` 짧은 이력, `012450` 09-25~29 정지(Open=0 모양), `000270` 10-01~02 정지(OHLC=직전 종가 모양), `000660` 09-25 시가 0(거래량 있음 → 정지 아님)
  - 장면마다 하루만 받기 실패: 미국 INDA(대기 주문 종목)·HTEL(보유 종목)·SPY(기준 지수), 국내 KS200
  - 폭락: 미국 2026-09-30, 국내 2026-10-08 종목 전부 종가 −30%
- 상태 폴더: 미국 `14-1005` 실행 전에 파이오니어 상태 파일을 손으로 고친다(이미 보유한 종목의 매수·보유 없는 종목의 매도·지갑보다 1주 많은 매도). 옛 파일·사람 손질로 상태가 어긋난 경우의 흉내
- `shutil.which`·`subprocess.run` → 가짜 claude(답 모양을 차례로 돌림: buy "0.9", hold, veto, 0.3, "모름", " VETO", "Hold", 답에서 빠짐, 0.5, "0.3", None, 0.75)
- `team.STATE_DIR`·`main.RESULTS_DIR` → 임시 폴더
- `main.datetime` → 시간대 있는 고정 시각 (`main.confirmed_bars` 의 `datetime.now`)
- `ANTHROPIC_API_KEY` → 가짜 값(claude 에 넘긴 환경에서 빠지는지 기록)

`main.load_prices`·`screener.scan`·`analyst.analyze`·`team.run_trainer` 등은 **진짜 코드**가 돈다.

## 다시 만들어야 할 때

- 운영 동작을 **일부러** 바꾸는 결정이 있을 때만(설계·사람 승인). H1 갈고리는 `h1=None` 에서 결과를 바꾸면 안 되므로 다시 만들 일이 아니다.
- `prompts/*.md`(팀장 페르소나)는 프롬프트 전체가 기록되므로 고치면 골든이 달라진다(설계 Q4: 프롬프트는 운영과 같게 둔다).
- `golden_scenarios.py` 의 장면 값(씨앗·날짜·답 모양·장면)을 바꿀 때. 이때도 반드시 **바꾸기 전 코드**(847ad13 또는 그 뒤 승인된 기준 커밋)의 worktree 에서 만든다.
- 골든 시험이 실패했다고 **지금 코드로 다시 만들면 안 된다**(자기와 비교가 된다). 먼저 환경 버전(위 표)과 코드 변경을 확인한다.
